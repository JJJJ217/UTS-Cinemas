# UTS-Cinemas

UTS-Cinemas is a SwiftUI-based cinema booking app to allow the users have a seamless booking experience.

## Features

- **User authentication**
  - Register and log in as customer or admin
  - Persistent local user storage

- **Movie browsing**
  - View movies in **Now Showing** and **Upcoming** sections
  - Movie cards with posters, ratings, genres, and descriptions
  - Trailer links for selected movies

- **Booking system**
  - Book seats for a movie session
  - View, edit, and cancel bookings
  - Track booking history per user

- **Seat selection**
  - Interactive seat grid
  - Prevents selection of already booked seats
  - Supports limited seat count per booking

- **Admin controls**
  - Add, edit, and delete movies
  - Manage cinema listings and schedules

## Tech Stack

- Swift
- SwiftUI
- Combine / ObservableObject
- Local JSON persistence
- Movie Database API

## Getting Started

1. Clone the repository: https://github.com/JJJJ217/UTS-Cinemas
3. Open the project by navigating UTS-Cinemas and click the file "UTS Cinemas" in Xcode
4. Build and run on a simulator or device

## Requirements

- macOS
- Xcode
- Swift
